# Installation v2.2.4d1

1. Die fehlerhafte aktuelle `index.html` sichern oder entfernen.
2. Die neue `index.html` aus diesem Paket in den bestehenden Simulatorordner kopieren.
3. Die vorhandene `index.html` ersetzen.
4. Den Simulator wie bisher über `index.html` starten.

Nur die `index.html` muss ersetzt werden. Die separate JavaScript- und JSON-Datei sind Dokumentations-/Wartungsdateien.
