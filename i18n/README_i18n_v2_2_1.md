# i18n Registry v2.2.1

`index.html` bleibt vollständig standalone. Die Dateien in diesem Ordner sind die kuratierbare Quelle für die nächsten Übersetzungsblöcke.

- Schlüsselregister: semantischer Ort → Nachricht
- Nachrichtenkatalog: eindeutiger deutscher Text → fünf Zielsprachen
- Coverage: fehlende/komplette Übersetzungen pro Bereich
- Glossar: geschützte Fachbegriffe und Muster

Bei künftigen deutschen Änderungen wird der `source_hash` verglichen; nur neue oder geänderte Texte müssen erneut übersetzt werden.
